# TREXO 🦖

Mission: Eat the stress. Absorb the chaos. Surface what matters. Make me
stronger.

TREXO is intended to become a local-first personal intelligence system that
learns from goals, commitments, knowledge and outcomes to reduce cognitive
load.

Status: Bootstrap / greenfield baseline.

## Development

- Prerequisite: [uv](https://docs.astral.sh/uv/)
- Install and sync dependencies: `uv sync`
- Verify the project: `.\scripts\verify.ps1`
- Read the project rules: `docs/constitution.md`

Future direction: product capabilities will be added only when they have a
defined need.
